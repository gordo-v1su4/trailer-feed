# Trailer Feed status

Updated 2026-10-05.

Trailer Feed is a portfolio and version review app. Import finished videos, watch and compare versions, and retain prompts and model metadata. It has no Raycast bridge dependency or generation controls. Creative Studio Pro is separate.

The live catalog is owned by the Robyn backend and SQLite volume; playback and upload storage use the trailer-feed RustFS bucket. The frontend is deployed by Vercel from main. See backend-deployment.md and rename-to-trailer-feed.md for runtime and migration details.

Earlier creation plans are historical and do not define current product behavior. A future LLM integration is outside the current scope.
